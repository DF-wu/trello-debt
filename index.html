    1. 連結 Trello

    授權頁顯示錯誤？改用手動方式

    Trello 的自動回跳需要在 Power-Up 設定的「Allowed origins」加入這個網站的網址。 不想設定的話，可以在新分頁開啟授權頁， 同意後把頁面顯示的 token 貼到上方 Token 欄位。

    2. 看板

    3. 分類規則

    每個分類對應看板上的一個清單，可加標籤與關鍵字（標題或內容含關鍵字時自動歸類）。

    4. 卡片格式

    可用變數：{title} {amount} {content} {date} {time} {category}
